# TASK-0073: Data Resilience Engine

## MỤC TIÊU
Đảm bảo hệ thống Bot quét cơ hội đầu tư (Market Screener) không bao giờ bị Crash (đứt gãy tiến trình) chỉ vì một vài mã cổ phiếu bị lỗi dữ liệu từ API hoặc do News Parser nhận diện nhầm.

## CHI TIẾT VẤN ĐỀ
- Tại Phase 20, hệ thống sử dụng module đọc tin tức RSS từ CafeF để phát hiện xúc tác (catalyst). Đôi khi hệ thống Regex bóc nhầm các từ khóa thông thường (Ví dụ "GOOD1") thành mã chứng khoán.
- Hàm `get_financial_ratios()` sẽ gọi `Finance(symbol="GOOD1", source="VCI").ratio()`. API vnstock quăng lỗi `ValueError: Invalid symbol`.
- Lỗi này lan truyền ngược lên `analyze_symbol()` và làm Crash toàn bộ quá trình quét danh mục, khiến các mã phía sau không được đánh giá, và không ghi được tệp `watchlist.json`.

## GIẢI PHÁP
- Tại `data_engine.py`, cập nhật hàm `get_financial_ratios(symbol)`: bọc đoạn gọi API VCI vào cấu trúc `try...except`.
- Nếu xảy ra lỗi (Exception), chỉ in ra cảnh báo (Warning) vào tệp Log và bỏ qua, thay vì kết thúc chương trình.
