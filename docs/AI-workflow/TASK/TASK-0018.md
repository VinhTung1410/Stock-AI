## 2. Tiêu chí Chấp thuận (Acceptance Criteria - AC)

- **AC-18.1 (Reference Structure & Manifest Management):**
  *Given* thư mục `docs/Reference/` đã phân bổ các nhóm con (`PTKT_Daily/`, `Stock_Analysis/`, `Insider_Trading/`, `Macro/`, `Archive/`),  
  *When* kiểm tra hoặc khởi tạo bộ theo dõi file,  
  *Then* file `manifest.json` ghi nhận danh sách file PDF kèm trạng thái `processed: false/true`, ngày báo cáo, và nguồn `TCBS`.

- **AC-18.2 (Daily Report Parser & Zero-Fabrication Rule):**
  *Given* file PDF báo cáo kỹ thuật hàng ngày trong `PTKT_Daily/` (ví dụ `20260930_BC_PTKT.pdf`),  
  *When* chạy script `scripts/parse_daily_reports.py`,  
  *Then*:
  - Script sử dụng `PyMuPDF` trích xuất văn bản từ PDF.
  - Trích xuất chính xác các trường: `date`, `source`, `source_file`, `extracted_at`, `market_regime_analyst`, `vnindex_support_zones`, `vnindex_resistance_zones`, `focus_sectors`, `risk_keywords`, `sentiment`, `raw_summary`.
  - Các trường không tìm thấy trong văn bản bắt buộc nhận giá trị mặc định (`[]` hoặc `"UNKNOWN"`), không bịa đặt số liệu.
  - Dữ liệu được ghi ra `data/market_context.json` và cập nhật `manifest.json` thành `processed: true`.

- **AC-18.3 (Context Engine & Non-Blocking Fail-Safe):**
  *Given* module `context_engine.py`,  
  *When* gọi `load_market_context(filepath, current_date)`:
  - Nếu file tồn tại và `date == current_date`: Trả về `MarketContext(is_valid=True, ...)`.
  - Nếu file không tồn tại, JSON bị hỏng, hoặc `date != current_date`: Tự động trả về fallback `MarketContext(is_valid=False)` và log warning, không phát sinh ngoại lệ làm sập chương trình.
  - Khi gọi `build_context_prompt_snippet(context)`: Nếu context hợp lệ, trả về đoạn văn bản định dạng markdown cô đọng cho AI prompt; nếu không hợp lệ, trả về chuỗi rỗng `""`.

- **AC-18.4 (Regime Conflict Arbitration):**
  *Given* xu hướng định lượng từ code `code_regime` (UPTREND, DOWNTREND, SIDEWAYS) và nhận định chuyên gia `analyst_regime` (UPTREND/BULLISH, DOWNTREND/BEARISH, SIDEWAYS/ACCUMULATION),  
  *When* gọi `check_regime_conflict(code_regime, analyst_regime)`,  
  *Then*:
  - Code UPTREND và Analyst DOWNTREND/BEARISH -> `conflict = True`, giải pháp: giảm 50% vị thế.
  - Code DOWNTREND và Analyst UPTREND/BULLISH -> `conflict = True`, giải pháp: giữ nguyên Cash Mode (Code thắng).
  - Code SIDEWAYS và Analyst ACCUMULATION -> `conflict = False` (tương thích).
  - Xu hướng tương đồng -> `conflict = False`.

- **AC-18.5 (Audit Trail & Database Migration):**
  *Given* file migration `migrations/0004_analyst_context.sql`,  
  *When* áp dụng migration vào cơ sở dữ liệu `decision_records`,  
  *Then* bảng được bổ sung các cột: `analyst_context_used` (BOOLEAN), `regime_conflict` (BOOLEAN), `context_source_file` (TEXT), `context_date` (DATE); và `SignalEvent` trong `ai_analyst.py` phản ánh đầy đủ các trường này.

- **AC-18.6 (Quality Gate & Code Standards):**
  *Given* toàn bộ mã nguồn mới và sửa đổi,  
  *Then* `ruff check .` đạt exit code 0, Cognitive Complexity $< 15$ trên mọi hàm, `logging.exception()` trong khối `except`, và bộ unit test đạt coverage $\ge 80\%$.
